PopTrans 隐私政策

本政策说明当前版本的 PopTrans 如何处理信息。

生效日期
2026 年 8 月 25 日
经营者
ZHANG WENTIAN
邮箱
ywhdt_zh@outlook.com

1. 适用范围

PopTrans 不运营接收翻译内容或 API 密钥的开发者服务器，也不包含广告、跟踪器或向经营者发送分析数据和崩溃报告的功能。

2. 保存在设备上的数据

PopTrans 将设置、试用状态和翻译历史保存在设备本地。服务商 API 密钥保存在系统提供的安全凭据存储中，不会写入普通设置、翻译历史或诊断日志。

你可以在应用内清理翻译历史、恢复设置并删除服务商凭据。由于凭据可能由系统单独保存，仅移除应用不一定会删除这些凭据。

3. AI 服务请求

只有在你测试连接或发起翻译时，PopTrans 才会直接连接你启用的 OpenAI、Gemini 或 DeepSeek。请求可能包含源文、源语言和目标语言、模型及相关设置、生成结果所需的指令，以及用于认证请求的 API 密钥。结果返回应用后可能保存在本地历史中。

服务商还可能自动接收与请求有关的网络信息（例如 IP 地址及由其推断的大致地区）、账号或 API 凭据标识、请求时间、用量和安全元数据。根据所用套餐和账号设置，服务商可能保留或审查请求，以提供和保护服务、计算用量、履行法律义务或改进服务。

这些数据由你选择的服务商按其条款和账号设置处理。经营者不会通过 PopTrans 服务接收你的翻译内容、结果或 API 密钥。服务商可能在其他国家或地区处理数据，具体保留方式和数据控制以其政策为准：

  • OpenAI 数据控制说明
  • Gemini API 附加条款
  • DeepSeek 隐私政策

PopTrans 只支持公开说明其数据保护和安全措施的服务商。要继续获得支持，服务商必须按照其公开政策和适用法律，为用户数据提供与本政策相同或等同的保护；如果经营者确认某服务商无法继续提供这种保护，PopTrans 将停止支持该服务商。

请勿翻译你无权发送的机密、敏感信息或他人的个人信息。

4. 设备功能

PopTrans 只会在你主动发起选区翻译时尝试读取当前选中文字。必要时，它可能短暂使用复制操作读取选区，并恢复此前的剪贴板内容。PopTrans 不持续收集你的键入内容。

当前版本的源文朗读在设备上完成，不会因朗读而把文本或音频发送给 AI 服务商。

5. 试用、购买与删除

试用状态保存在设备本地。购买和恢复由你取得应用的分发平台处理；经营者不会直接收到完整的支付卡信息。交易数据的处理适用相应分发平台的政策。

本地数据会保留到你在应用内删除、重置或移除相应本地存储为止。服务商对请求和账号数据的保留由其政策及你的账号设置决定；经营者无法访问或代为删除你在服务商账号中的数据。

若要撤回 PopTrans 向某服务商发送未来请求的许可，请停止使用该服务商并在应用中删除其凭据；此后 PopTrans 不会再向其发送新内容。删除服务商已持有的数据需使用该服务商的账号控制或直接联系服务商，经营者无法代为处理。

PopTrans 使用系统安全凭据存储和加密网络连接，但任何系统都无法保证绝对安全。PopTrans 不面向儿童；使用在线服务时，也应符合所选服务商的最低年龄要求。

如果数据处理方式发生实质变化，本政策会更新生效日期。如有隐私问题，请联系 ywhdt_zh@outlook.com。
