PopTrans 隐私政策

生效日期

经营者
ZHANG WENTIAN

1. 本地数据

设置、提示词模板、试用状态和翻译历史保存在设备上。API 密钥由系统安全存储，不写入普通设置、历史或诊断日志；提示词预览不写入历史。

PopTrans 无广告、跟踪器或开发者分析服务，也不通过开发者服务器接收你的翻译内容或密钥。

2. 云端请求

只有你主动发起请求并允许当前服务接收数据时，文本、语言及提示词才会发送到云端。默认使用 Apple Private Cloud Compute，无需第三方 API 密钥。Apple 说明 PCC 不保留请求内容或结果，Apple 也无法访问这些内容；可能收集不含内容且不关联账号的请求大小、用时等有限元数据。

你也可以选择 OpenAI 或 Gemini，使用自己的 API 密钥。请求直接发往所选服务，包含文本、提示词和模型设置；服务商还可能收到 IP 地址、大致地区、账号及用量信息。数据使用和保留方式取决于其政策、套餐及账号设置，处理地点可能在其他国家或地区。

网络请求采用加密连接。数据接收方须提供与本政策及适用规则相同或等同的数据保护。使用云端服务时，也须符合其年龄要求。

  • Apple Intelligence 与隐私说明
  • OpenAI 数据控制说明
  • Gemini API 附加条款

在设置中撤回当前服务的许可可停止后续请求；切换服务不会自动授权另一服务，撤回许可也不会删除已保存的密钥。

请勿发送你无权提供的机密、敏感信息或他人的个人信息。

3. 设备功能

选区翻译仅接收来源应用通过系统服务传入的文字。PopTrans 不请求辅助功能权限、不读取其他应用界面、不模拟复制，也不监控全局按键。

源文朗读在设备上完成，不向 AI 服务商发送文本或音频。

4. 购买与删除

购买和恢复由应用的分发平台处理，经营者不接收支付卡信息。

本地数据保留到你删除历史、重置设置或移除对应存储为止。你可在应用内另行删除密钥；仅移除应用不一定会删除系统保存的凭据。

云端数据的删除需通过所选服务的账号控制或联系服务商处理，经营者无法代为访问或删除。
