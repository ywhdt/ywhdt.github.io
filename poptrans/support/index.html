常见问题

开始翻译需要 API 密钥吗？

默认无需第三方密钥。先在应用设置中检查服务状态：设备须支持并启用 Apple Intelligence，服务在当前语言与地区可用，并保持联网。准备就绪后开启试用或恢复完整版，确认数据发送许可。只有可选云端服务需要自己的密钥。

为什么选区翻译没有响应？

先尝试来源应用「服务」菜单中的「使用 PopTrans 翻译」，再检查系统服务快捷键及按键冲突。无需辅助功能权限；不兼容时可在工作台输入或粘贴。

为什么翻译失败？

检查网络、数据发送许可和应用授权，并查看设置中的服务状态。完整版不增加云端使用限额；可选服务的密钥、额度或账单问题请联系服务商。

如何清除本地数据？

你可以在应用内清除翻译历史、恢复设置或删除服务商凭据。仅移除应用不一定会删除由系统单独保存的凭据。

试用或购买遇到问题怎么办？

在应用内重试或恢复购买。仍有问题请发送邮件，注明取得应用的渠道，不要附付款信息。
