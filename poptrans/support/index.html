常见问题

如何设置 API 密钥？

在应用的服务设置中选择服务商，填写密钥和模型，然后运行连接测试。密钥由系统安全存储。

为什么快捷键没有读取到选中文字？

确认选区翻译快捷键已启用，并按照应用内提示检查读取选区所需的系统权限。完成更改后，重新打开应用再试。

为什么翻译失败？

先运行连接测试，并检查网络、API 密钥、模型名称和服务商额度。账号、账单或额度问题需要联系对应服务商。

如何清除本地数据？

你可以在应用内清除翻译历史、恢复设置或删除服务商凭据。仅移除应用不一定会删除由系统单独保存的凭据。

试用或购买遇到问题怎么办？

先在应用内重试或选择恢复购买。若仍无法解决，请在邮件中说明应用版本和取得应用的渠道，但不要发送完整付款信息。

有关数据处理方式，请查看 PopTrans 隐私政策。
