Audelue 隐私政策

本政策说明 Audelue 如何处理音频、字幕、购买信息及其他相关数据。

1. 音频与本地历史

Audelue 在你启动会话并授予权限后，处理所选的系统、应用或麦克风音频，用于转写及可选翻译。屏幕录制权限只用于获取音频，不录制屏幕视频。Apple 本地模式在设备上处理音频和字幕，不发送到云端。

应用不保存录音。设置、关键词和翻译偏好保存在本机。开启历史后，字幕和相关会话信息保留到你删除为止，可供回看和导出，不会自动同步到云端。

2. 使用云端 Pro 时

使用 Pro 时，设备直接将音频及相关语言、关键词等信息发送给 Soniox，进行转写及可选的实时翻译。选择质量翻译时，相关原文、必要上下文和翻译偏好会经过 Audelue 服务器发送给 DeepSeek，不发送音频。

音频不经过 Audelue 服务器；质量翻译文本只用于即时处理，不在服务器保存。云端传输使用加密连接，Audelue 服务器由 Microsoft Azure 托管。

云端处理可能发生在你所在国家或地区之外。服务商对收到的数据有各自的处理和保留政策，请在启用前查阅：Soniox · DeepSeek。

3. 云端余额与购买信息

为管理 Pro 余额、恢复未用时长、处理退款及防止重复发放，我们在提供服务期间保存必要的购买、用量、试用和设备授权信息。这些记录不包含音频、字幕或翻译偏好正文。

购买由 Apple 处理，我们不接收银行卡资料或你的 Apple 账户邮箱、密码。相关数据处理适用 Apple 隐私政策。我们也使用必要的运行状态和错误信息维护服务，不记录音频或字幕内容。

4. 你的选择与删除

你可以随时暂停或结束会话、撤回云端处理同意，或在设置中删除历史、解除设备授权及删除云端账户。撤回同意会停止新的云端处理，不会删除本地历史或剩余时长。关闭历史保存不会删除已有历史。

删除云端账户会结束云端会话，并清除设备关联和授权资料。本地历史需另行删除；用于余额恢复、退款、防止重复发放及账户安全的必要记录仍会保留。旧备份会在七天内清除。

卸载应用不会删除云端记录，导出文件和设备备份需由你另行管理。已发送给服务商的数据不会随本地删除而移除，如需申请删除，请联系我们。

5. 网站与支持

应用和网站没有广告或使用行为分析。网站由 GitHub Pages 托管，不使用追踪 Cookie。GitHub 对访问资料的处理见 GitHub 隐私声明。

发送支持邮件时，开发者和邮件服务商会收到你的邮箱、正文及附件，仅在处理问题或法律义务所需期间保留。你可以请求删除支持资料。

6. 联系与更新

Audelue 面向 18 岁及以上用户，开发者和运营者为 ZHANG WENTIAN。如有隐私问题或希望访问、更正、删除相关资料，请联系 wentianzh.apps@outlook.com。政策变更会在本页公布。
