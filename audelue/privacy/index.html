Audelue 隐私政策

生效日期：2026-09-12

1. 适用范围

本政策适用于 macOS 版 Audelue 及其官网。开发者和维护者为 ZHANG WENTIAN，联系邮箱为 wentianzh.apps@outlook.com。

Audelue 不要求注册开发者账号，也没有接收你的音频、字幕或 API Key 的自有业务服务器。应用不包含广告或第三方分析 SDK，不自动向开发者发送使用分析或崩溃报告。选择云端引擎时，数据会直接发送给相应服务商。

2. 音频与系统权限

应用仅在你启动会话并授予必要权限后，处理所选系统音频、应用音频或麦克风音频。系统混音可能包含多个应用的声音；屏幕与系统音频录制权限用于音频捕获，不用于保存屏幕视频。

原始音频仅临时保存在内存中，用于转写、翻译及必要的处理或重试。Audelue 不保存录音文件，并在相关处理或会话结束后释放音频。Apple 本地转写和本地翻译在设备上处理内容，语言资源下载、系统诊断或购买可能仍需连接 Apple 服务。

3. 本机保存的信息

设置保存在本机，包括界面语言、引擎与语言选择、字幕外观和服务处理同意。你输入的上下文、关键词、翻译偏好及术语也可按模型保存到本机普通设置中；这些内容可能包含敏感信息，不属于 Keychain 保护的密钥。

开启历史时，应用可保存最终原文与译文、时间、语言、来源类型、模型、处理状态、必要配置及服务商报告的用量摘要。不会保存每一次临时字幕修订、提示词正文、API Key 或原始音频。历史存储在本地，不通过应用同步到其他设备。

API Key 保存在系统 Keychain，不写入普通设置、历史或应用日志，也不由应用同步到其他设备。本地历史和设置依赖 macOS 及你的设备保护措施，未另加应用层数据库加密。系统备份可能包含本地数据；自行导出的字幕由你选择的保存位置和同步设置管理。

4. 云端处理与接收方

每个云服务分别获得你的处理同意，并使用你自己的凭据。云转写和语音翻译会发送必要音频；云文本翻译会发送原文、有限前文、目标语言及生成所需指令。按所选路线，还可能发送你填写的上下文、关键词或翻译偏好。原文与翻译使用不同服务时，两家服务会分别收到对应数据。历史中的手动翻译重试也会发送相关原文与必要前文。

“测试连接”只进行连通与认证所需的元数据请求，不发送音频、字幕或提示词。保存 Key 本身不会触发该检查。网络请求会向相应服务提供认证信息，并暴露 IP 地址、请求时间、模型、用量及安全相关元数据。

服务商可能依据你的账户方案、区域和设置，在其他国家或地区处理数据，并为服务、安全或法定义务保留信息。其内容保留与训练规则各不相同：例如，Gemini 未付费服务可能将输入输出用于产品改进及人工审阅；涉及敏感信息时请先检查相应条款，勿向不适合该内容的服务发送信息。

  • OpenAI — API data controls
  • Google — Gemini API terms
  • Microsoft — Speech data privacy
  • Soniox — Privacy Policy

应用不承诺所有云服务均不保留数据或不用于训练。请在启用前查看对应服务当前政策及你的账户数据控制选项。

我们要求受支持的服务商，在本政策披露的处理范围内，提供与本政策及适用要求相同或同等的数据保护。我们会复核其公开政策；若发现无法满足这些要求，将调整或停止相应服务支持。

5. Apple 购买与诊断

购买、恢复和家庭共享由 Apple 的 App Store 与 StoreKit 处理。Audelue 读取经验证的商品和交易权益信息，以判断完整版是否可用，并响应退款或共享撤销；不接收你的支付卡资料，也不将交易凭证上传到开发者服务器。

Apple 可能依照你的系统或 TestFlight 设置收集诊断和测试反馈，并向开发者提供相关报告。此类系统服务与应用自行上传数据不同，受 Apple 隐私政策及相应设置约束。

6. 你的控制与删除

  • 暂停或结束会话可以停止继续接收音频；正常结束会完成已经接收内容的处理。
  • 在“设置 → 云端与隐私”中撤回某个服务的同意，可停止该服务的后续请求；使用中的相关会话会取消。
  • 在同一页面删除 Key、清除保存的提示词数据；正在使用的 Key 需结束会话后删除。
  • 关闭后续历史保存、删除单条会话或清空历史；已有导出文件和系统备份需单独管理。

撤回同意或删除本地记录不能收回已经发送的数据。服务商保存的信息需通过其账户控制或隐私渠道处理。卸载应用不保证同时删除独立保存的 Keychain 凭据、备份或导出文件。

7. 网站与支持邮件

本网站为 GitHub Pages 托管的静态页面，不设置广告、分析脚本、追踪 Cookie 或在线表单。GitHub 为提供和保护托管服务，可能处理访问时的 IP 地址和请求信息，详见 GitHub 隐私声明。打开本网站不会附带应用里的音频、字幕或 Key。

主动发送支持邮件时，开发者及邮件服务商会收到你的邮箱地址、邮件正文和你附加的资料，用于回复和处理问题。请仅提供必要信息；支持往来按处理问题及必要法律义务所需时间保留，可联系请求删除。

8. 使用与隐私请求

请仅处理你有权捕获和发送给相关服务的音频，并在需要时获得参与者同意。字幕与翻译可能出错，不能替代专业判断。不同服务有各自的年龄、地区和账户使用条件。

如对开发者持有的支持资料有访问、更正、删除或其他适用隐私权请求，请联系下方邮箱。对仅存于你设备的数据，可使用应用提供的删除入口；开发者无法远程读取或代你恢复这些记录。

9. 政策更新与联系

数据处理方式发生变化时，我们会更新本页和生效日期，并按需要调整应用内告知与商店隐私信息。联系：wentianzh.apps@outlook.com。
