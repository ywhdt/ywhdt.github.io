Audelue 隐私政策

Audelue 不要求注册账号。应用不会向开发者上传你的音频、字幕或 API Key；是否使用云服务，由你选择。

生效日期：2026-09-20

1. 音频与字幕

只有在你启动会话并授予必要权限后，Audelue 才会处理你选择的系统、应用或麦克风音频，用于生成字幕或翻译。屏幕与系统音频录制权限仅用于获取音频，不用于录制屏幕视频。

应用不保存录音，临时音频会在处理或会话结束后释放。选择 Apple 本地引擎时，字幕和翻译内容在设备上处理。

2. 保存在你 Mac 上的信息

设置、你填写的提示和翻译偏好保存在本机。开启历史后，字幕、译文及相关会话信息会保留到你删除为止，供你回看和导出。处理失败时，历史可能附带不含正文或密钥的错误记录。

API Key 使用 macOS 钥匙串保护；其他本地内容依赖你的设备安全保护。Audelue 不主动将这些数据同步到其他设备。

3. 使用云服务时

你可以选择 OpenAI、Google Gemini、Microsoft Azure、Soniox 或 DeepSeek，并分别授权。Audelue 使用你的 API Key，直接连接你选择的服务：

  • 语音识别和语音翻译：发送所选音频及你填写的相关提示。
  • 文字翻译：发送字幕、必要的前文、语言和翻译偏好。DeepSeek 仅接收文字，不接收音频。

服务商还会收到 IP 地址、服务用量等连接信息，并按其政策及你的账户设置处理和保留数据。这可能涉及跨境处理、内容改进或人工审阅。请在启用前查阅相应说明：

OpenAI · Google Gemini · Microsoft Azure · Soniox · DeepSeek（服务条款、隐私政策）

4. 你的选择与删除方式

  • 暂停或结束会话，停止接收新的音频。
  • 在“设置 → 云端与隐私”撤回服务授权、删除 API Key，或清除保存的提示词数据。撤回授权会停止该服务的后续请求。
  • 关闭历史保存，或删除单条、全部历史。关闭保存不会删除已有记录。

已导出的文件和系统备份需要另行管理，卸载应用也不一定会删除钥匙串中的 Key。已经发送给服务商的数据无法由 Audelue 收回，请通过相应服务的账户设置或隐私渠道申请删除。

5. 购买、网站与支持

购买、恢复和家庭共享由 Apple 处理。Audelue 只接收确认完整版权益所需的信息，不接收银行卡资料。Apple 还可能根据你的系统或 TestFlight 设置提供诊断与反馈，详见 Apple 隐私政策。

应用和网站不包含广告或使用行为分析。网站由 GitHub Pages 托管，不使用追踪 Cookie；GitHub 可能记录 IP 地址等访问资料以提供和保护服务，详见 GitHub 隐私声明。

发送支持邮件时，开发者及邮件服务商会收到你的邮箱地址、正文和附件，用于回复和处理问题。资料仅在处理问题或履行法律义务所需期间保留，你可以联系请求删除。

6. 联系与政策更新

本政策适用于面向18岁及以上用户的 Audelue macOS 应用及本网站。开发者和维护者为 ZHANG WENTIAN。

如有隐私问题，或需要访问、更正、删除你提供的支持资料，请联系 wentianzh.apps@outlook.com。政策变更会在本页公布并更新生效日期。
