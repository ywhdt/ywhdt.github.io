Audelue 使用与支持

开始使用

  1. 在 macOS 26 或更新版本中打开 Audelue，选择转写、转写并翻译或语音直译，再选择引擎与语言。
  2. 选择系统混音、指定应用或麦克风，并按系统提示授权。
  3. 点击开始。会话中可以随时暂停、继续或结束。

连接云端引擎

打开“设置 → 云端与隐私”，选择服务、允许数据处理，并保存你自己的 API Key。Microsoft Azure 还需要填写与你的资源匹配的 Speech 端点。点击“测试连接”检查配置。

云端费用由服务商另行收取，不包含在 Audelue 完整版中。

调整双语与 Live 字幕

在字幕设置中调整原文与译文的上下顺序、字号和各自的行数。行数可选自动或一至四行；自动模式下，中文、日文默认一行，拉丁文字默认两行。

标有 Live 的引擎会随语音逐步显示字幕。

没有声音或字幕

确认音源正在播放、会话未暂停，且源语言选择正确。检查 macOS“系统设置 → 隐私与安全性”中的麦克风或屏幕与系统音频录制权限；更改权限后可能需要重新打开应用。

若某个应用没有声音，可先用本地音频文件测试。部分应用或受保护内容可能无法捕获。

试用、购买与恢复

免费会话最多运行 3 分钟，暂停时间不计入。到时限后仍可查看本次字幕与历史。一次性购买完整版可解除单次会话时长限制。

在“设置 → 通用 → 完整版”中查看购买选项。若已购买却未解锁，请确认使用原购买账户，再点击“恢复购买”。

管理历史与隐私

在历史窗口回看、导出或删除会话，也可清空全部历史。关闭历史保存不会删除已有记录；已导出的文件需单独删除。

在“设置 → 云端与隐私”中管理服务授权、API Key 和保存的提示词。数据处理与删除详情见隐私政策。

联系支持

发送邮件至 wentianzh.apps@outlook.com，附上应用与 macOS 版本、音频来源、引擎与语言、复现步骤和错误提示。
