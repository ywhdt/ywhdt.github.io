Audelue 使用与支持

从第一条字幕开始。

开始使用使用本地或 Pro调整字幕没有声音或字幕时长、购买与恢复管理历史与隐私联系支持

开始使用

  1. 在运行 macOS 27 或更新版本的 Apple 芯片 Mac 上打开 Audelue，选择本地或 Pro，并设置音频语言及可选翻译。
  2. 选择系统混音、指定应用或麦克风，并按系统提示授权。本地模式可能需要先下载相应语言资源。
  3. 点击“开始字幕”。会话中可以随时暂停、继续或结束。

使用本地或 Pro

本地模式使用 Apple 在设备上转写，并可选择本地翻译，免费且不设会话时长限制。可用语言取决于设备支持及已准备的语言资源。

Pro 使用云端转写，翻译可以关闭，也可选择实时或质量模式。全部 Pro 模式共用同一时长余额，无需填写 API Key，也不需要另向服务商付费。

首次使用 Pro 时，阅读并同意云端处理说明，按系统提示完成 App Store 归属验证，再领取试用或购买时长。本地使用不需要云端授权或余额。

调整字幕

在“设置 → 字幕”中调整原文与译文的上下顺序、字号、窗口宽度和各自的最大行数。每种语言可选一至四行，默认两行；也可以选择只显示原文或译文。

Pro 原文字幕随语音逐步出现，翻译可能稍后显示。结果取决于音源清晰度、语言及所用模式。

没有声音或字幕

确认音源正在播放、会话未暂停，且音频语言选择正确。在 macOS“系统设置 → 隐私与安全性”中检查麦克风或屏幕与系统音频录制权限；更改权限后可能需要重新打开应用。

本地模式请确认相应语言资源已准备；Pro 请检查网络、余额及应用中的错误提示。如果一个应用没有声音，可先用本地音频文件测试。部分应用或受保护内容可能无法捕获。

时长、购买与恢复

新用户可领取一次 20 分钟 Pro 试用，可分多次会话使用，不会自动扣款。时长包提供 1、5、10 小时，在“设置 → 云端与隐私”中查看余额和购买选项；价格以应用内显示为准。已购时长不设到期日。

全部 Pro 模式按会话运行时间一比一计时，与是否翻译无关。运行中的静音、无字幕和正常处理等待也计时；暂停 Audelue、系统睡眠、结束后的收尾或确认服务受阻期间不计时。只暂停音源播放器不会暂停 Audelue。

换机、重装或余额未显示时，确认使用原来的 App Store 账户，点击“恢复购买与余额”，并完成系统要求的认证。恢复的是服务端未用时长，不会重复发放已使用时长或已领取的试用。

余额耗尽后，会话停止接收新音频并完成已接收内容。你可以购买时长或另开本地会话；应用不会自动续购。

管理历史与隐私

在历史窗口回看、导出或删除会话，也可清空全部历史。关闭历史保存不会删除已有记录；已导出的文件需单独删除。本地历史不会自动同步到云端。

在“设置 → 云端与隐私”中撤回云端处理同意、解除本设备授权或删除云端账户。撤回同意会停止新的云端处理，保留本地历史和剩余时长。云端数据处理、保留及删除范围见隐私政策。
