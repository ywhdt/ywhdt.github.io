开始使用

  1. 使用 macOS 26 或更新版本，打开 Audelue。
  2. 选择转写、转写并翻译或语音翻译，再选择引擎与语言。
  3. 选择系统混音、指定应用或麦克风，并按系统提示授权。系统混音可能同时包含其他应用的声音。
  4. 点击开始。可暂停、继续或结束会话；在设置中调整字幕顺序、字号与行数。

初次使用可先选择 Apple 本地转写；部分语言需要下载系统资源。云端引擎需另行配置。

连接云端引擎

打开“设置 → 云端与隐私”，选择服务、允许该服务处理数据，并保存你自己的 API Key。Microsoft Azure 还需要与你的资源匹配的 Speech 端点。随后可以点击“测试连接”。

连接成功表示连通与认证检查通过，不保证所有模型、区域或额度均可用。云端费用由对应服务商收取，不包含在 Audelue 的完整版中。

调整双语与 Live 字幕

在字幕设置中选择原文或译文在上，并分别设置显示行数。自动行数对中文、日文默认一行，对拉丁文字默认两行，也可自选一至四行。

标有 Live 的引擎会提供增量字幕。其他路线需等待音频段处理结果；译文也可能晚于原文。两条语言轨道会分别推进。

没有声音或字幕

先确认音源正在播放、应用未暂停、源语言选择正确。检查 macOS“系统设置 → 隐私与安全性”中的麦克风或屏幕与系统音频录制权限；权限变更后可能需要重新打开应用。

系统显示的录制授权名称可能包含“屏幕”，Audelue 的生产捕获只处理音频，不保存屏幕视频。若特定应用没有音频，请尝试普通本地音源；受保护内容和部分应用可能无法捕获。

试用、购买与恢复

免费会话累计运行最多 3 分钟，暂停时间不计入。到时限后，应用完成已接收内容的处理并保留会话窗口；可查看字幕或历史。

完整版只解除单次会话时长限制。正式发布后，可从“设置 → 通用 → 完整版”购买或恢复；取消购买不会解锁，待批准交易需完成批准后生效。当前商品尚未公开，暂时无法购买是预期状态。

正式商品计划开放家庭共享，实际可用性以 App Store 商品和家庭设置为准。后续若购买未恢复，请确认使用原购买账户，并通过应用内“恢复购买”重新检查。

管理历史与隐私

关闭历史保存仅影响后续会话，不会删除已有记录。你可以在历史窗口导出、删除单条会话或清空历史。原始音频不作为历史保存，已导出的文件需要在保存位置自行删除。

在“云端与隐私”中，可撤回某个服务的处理同意、删除 Key 或清除保存的提示词数据。正在使用的 Key 需结束会话后再删除。撤回同意不会删除服务商已经收到的数据，详情见隐私政策。

联系支持

发送邮件至 ywhdt_zh@outlook.com。请说明应用版本或构建号、macOS 版本、音频来源、所用引擎与语言、复现步骤及错误提示。

请不要发送 API Key、购买凭证全文或包含他人隐私的录音与字幕。截图前请遮盖敏感内容。联系邮件只用于处理支持请求；隐私或删除请求也可使用此邮箱。
