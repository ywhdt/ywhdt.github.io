Audelue 内部测试版隐私政策

本政策适用于通过 TestFlight 分发的 Audelue 内部测试版。

本地处理无需注册账号。使用云端 Pro 时，你不需要填写服务商 API Key；我们会验证 App Store 归属，以关联你的云端余额。

1. 音频与本地历史

只有在你启动会话并授予必要权限后，Audelue 才处理所选的系统、应用或麦克风音频，用于转写及可选翻译。屏幕录制权限用于获取音频，不用于录制屏幕视频。Apple 本地模式在设备上处理音频和字幕，不发送给 Audelue 云端服务。

应用不保存录音。设置、关键词及翻译偏好保存在本机；开启历史时，原文、译文及相关会话信息保留到你删除为止，供回看和导出。这些历史不自动同步到云端。

2. 使用云端 Pro 时

此内部 TestFlight 版本通过 Audelue 的服务器，将音频发送给所选的 Soniox 或 Microsoft MAI；实时翻译由 Soniox 处理，文字翻译由所选的 DeepSeek 或 Google Gemini 处理。

相关语言、必要前文、关键词和翻译偏好也会发送给对应服务商。Audelue 的服务器仅在处理期间临时持有音频和字幕内容，不保存为服务器历史。云端数据传输使用加密连接；设备授权凭据由 macOS 钥匙串保护。

云端基础设施由 Microsoft Azure 托管。云端处理可能发生在你所在国家或地区之外。模型服务商按照各自政策处理和保留收到的数据；Audelue 的保留政策不代替服务商的政策，请在启用前查阅：Soniox · DeepSeek · Microsoft Speech · Google Gemini。

3. 云端余额与购买信息

我们使用 Apple 提供的应用及购买验证信息关联余额，并保存必要的交易、时长用量、一次试用和设备授权记录，用于恢复未用时长、处理退款，以及防止购买或试用重复发放。这些记录不包含音频、字幕或翻译偏好正文；我们在提供上述服务期间保留必要记录。

购买由 Apple 处理，我们不接收银行卡资料，也不读取你的 Apple 账户邮箱或密码。Apple 可能根据系统或 TestFlight 设置提供诊断及反馈，详见 Apple 隐私政策。

为维护服务稳定性，我们处理有限的故障类别、计数和耗时，不记录音频、字幕、提示词或密钥正文。

4. 你的选择与删除

你可以暂停或结束会话、撤回后续云端处理同意，或在设置中解除本设备授权、删除云端账户。撤回同意会停止新的云端处理，并保留本地历史和剩余时长。关闭历史保存不会删除已有历史；单条或全部历史可以另行删除。

删除云端账户会结束云会话并清除设备关联及验证资料。本地历史不会随之删除。用于余额恢复、退款及防重复的必要记录，以及必要撤销记录仍会保留；旧备份在七天内轮换淘汰。

之后主动恢复时，我们重新验证 App Store 归属，只恢复实际未用时长，不重新发放已消费时长或已领取的试用。普通启动和本地模式不会自动恢复云端账户。

已导出的文件及设备备份由你另行管理；卸载应用不等同于删除云端记录。Audelue 无法收回服务商已收到的数据，如需申请删除，可以联系我们。

5. 网站与支持

应用和网站不包含广告或使用行为分析。网站由 GitHub Pages 托管，不使用追踪 Cookie；GitHub 可能处理访问资料以提供和保护托管服务，详见 GitHub 隐私声明。

发送支持邮件时，开发者及邮件服务商收到你的邮箱、正文和附件，用于处理问题，仅在处理或法律义务所需期间保留。你可以联系请求删除支持资料。

6. 联系与更新

本政策适用于面向 18 岁及以上用户的此版本。开发者和运营者为 ZHANG WENTIAN。如需了解、访问、更正或删除相关资料，请联系 wentianzh.apps@outlook.com。政策变更会在本页公布。
