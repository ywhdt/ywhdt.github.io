Audelue 内部测试版隐私政策

适用于通过 TestFlight 分发的 Audelue 内部测试版。

1. 音频与历史2. Pro 云端处理3. 余额与购买4. 撤回同意与删除5. 网站与支持6. 联系与更新

1. 音频与历史

开始会话并授权后，Audelue 才处理所选音频。本地模式在设备上转写和翻译，不上传音频或字幕；屏幕录制权限仅用于取音，不录制视频。

应用不保存录音。设置留在本机；开启历史后，字幕及会话信息保留至你删除，不自动同步到云端。

2. Pro 云端处理

同意云端处理后，设备直接向 Soniox 发送音频、语言设置及关键词，进行转写和可选的实时翻译。质量翻译将原文、必要上下文及偏好经 Audelue 服务器发送给 DeepSeek 或 OpenAI；主服务不可用时，同一文本可能交由另一家处理。

内部测试另提供 Microsoft MAI 音频直连转写，以及经 Audelue 服务器的 Google Gemini 文本翻译。

音频不经过 Audelue 服务器；翻译文本仅作即时处理，不在服务器保存。连接加密，服务器由 Microsoft Azure 托管。处理可能发生在境外，服务商按各自政策保留数据：Soniox · DeepSeek · OpenAI · Microsoft Speech · Google Gemini。

3. 余额与购买

我们通过 Apple 应用及购买验证信息关联余额，在提供服务期间保留必要的购买、用量、试用和设备授权记录，用于恢复未用时长、退款和防止重复发放。这些记录及运行状态、错误记录不含音频、字幕或翻译偏好正文。

购买由 Apple 处理，我们不接收银行卡资料或 Apple 账户邮箱、密码。Apple 的诊断及数据处理见 Apple 隐私政策。

4. 撤回同意与删除

可在“设置 → 云端与隐私”撤回同意，停止新的云端处理，保留历史和剩余时长。历史需单独删除；关闭历史保存不会删除已有记录。

解除设备授权或删除云端账户，请联系我们。删除账户会结束云端会话并清除设备关联及授权资料；余额恢复、退款、防重复及安全所需的记录仍会保留，旧备份七天内清除。

卸载应用不删除云端记录。导出文件及设备备份需另行管理；服务商已收到的数据也不会随本地删除而移除，可联系我们申请删除。

5. 网站与支持

应用和网站无广告或使用行为分析，不使用追踪 Cookie。网站托管方对访问资料的处理见 GitHub 隐私声明。

支持邮件的地址、正文及附件由开发者和邮件服务商接收，按处理问题或法律义务所需保留，可联系我们请求删除。

6. 联系与更新

Audelue 面向 18 岁及以上用户，由 ZHANG WENTIAN 开发运营。访问、更正、删除资料或其他隐私问题，请联系 wentianzh.apps@outlook.com。政策更新在本页公布。
