Get started

  1. Open Audelue on an Apple silicon Mac running macOS 27 or later. Choose Local or Pro, then set the audio language and optional translation.
  2. Select system mix, a specific app, or the microphone, and grant the requested permissions. Local mode may require language resources to be downloaded first.
  3. Select Start Captions. You can pause, resume, or finish the session at any time.

Use Local or Pro

Local mode uses Apple’s on-device transcription and optional local translation. It is free, with no session time limit. Available languages depend on device support and prepared language resources.

Pro uses cloud transcription, with translation off, Real-time translation, or Quality translation. All Pro modes share one time balance. No API key setup or separate provider payment is needed.

Before using Pro, read and accept the cloud processing information, complete App Store ownership verification if prompted, then claim the trial or purchase time. Local mode requires no cloud authorization or balance.

Adjust captions

In Settings → Subtitles, adjust the order, text size, window width, and maximum line count for source captions and translation. Each language can use one to four lines, with two by default. You can also show only the source or translation.

Pro source captions appear as speech unfolds; translation may follow later. Results depend on audio clarity, language, and the selected mode.

No audio or captions

Check that your source is playing, the session is not paused, and the audio language is correct. Check microphone or screen and system audio recording permissions in macOS System Settings → Privacy & Security. You may need to reopen the app after changing a permission.

For Local mode, check that the language resources are ready. For Pro, check the network, balance, and any error shown in the app. If one app produces no audio, try a local audio file. Some apps and protected content may not be capturable.

Time, purchases, and restore

New users can claim one 20-minute Pro trial and use it across multiple sessions, with no automatic charge. Time packs offer 1, 5, or 10 hours. View your balance and purchase options in Settings → Cloud & Privacy; prices are shown in the app. Purchased time does not expire.

All Pro modes use time at the same rate: one minute of running uses one minute of balance, whether or not translation is enabled. Silence, no captions, and normal processing waits still count while running. Pausing Audelue, system sleep, finishing work after the session ends, or a confirmed service interruption does not count. Pausing only the source player does not pause Audelue.

After changing Macs or reinstalling, or if your balance is missing, check that you use the original App Store account. Select Restore Purchases and Balance and complete any system authentication. Restore recovers unused server balance; it does not grant consumed time or the trial again.

When your balance runs out, the session stops receiving new audio and finishes work already accepted. You can purchase time or start a separate Local session. The app does not automatically buy more time.

Manage history and privacy

Revisit, export, or delete sessions in the history window, or clear all history. Turning history saving off keeps existing records. Delete exported files separately. Local history is not automatically synced to the cloud.

In Settings → Cloud & Privacy, withdraw cloud processing consent, disconnect this device, or delete the cloud account. Withdrawing consent stops new cloud processing and keeps local history and remaining time. See the privacy policy for cloud processing, retention, and deletion details.

Contact support

Email wentianzh.apps@outlook.com with your app and macOS versions, audio source, Local or Pro mode and languages, steps to reproduce, and error message.

Do not send API keys, private recordings, or captions. Redact sensitive information in screenshots.
