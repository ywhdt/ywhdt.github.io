Before you begin

Which Macs are supported?

An Apple silicon Mac running macOS 27 or later is required. Language resources and individual features depend on system support.

Can I caption any app?

Choose system audio, a specific app, or a microphone for content you have the right to process. Capture requires macOS permission. Protected content is not guaranteed to work.

Do I need to pay?

Apple local mode is free. Eligible App Store accounts can claim one 20-minute Pro trial, then buy time packs as needed.

Does time count while paused or silent?

Pro uses the time a session is running. Pausing stops usage. Silence still counts while the session is running.

Do history and balance sync across devices?

Restore your Pro balance on devices with the same Apple-verified ownership. Caption history stays on each Mac and does not automatically sync to the cloud.

Do I need an API key?

The public version needs no provider keys or separate Audelue login. Choose local mode or an available Pro service.
