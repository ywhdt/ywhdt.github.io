サポート

Skinfoldの使用にアカウントやインターネット接続は必要ありません。問題が発生した場合は、まず以下の説明をご確認ください。解決しない場合は、開発者のWENTIAN ZHANGまでお問い合わせください。

サポートにメール GitHub Issueを作成

よくある質問

計算できない場合

入力欄の下に表示される案内に従い、年齢と測定値を確認してください。各部位に有効な測定値が1回あれば計算できます。一致を比較する場合は、2回目または3回目の測定値を追加してください。測定単位はミリメートルとインチを切り替えられます。3部位の平均値の合計が120 mm（4.724 in）を超える場合、本アプリでは体脂肪率を推定できません。

ほかの測定結果と異なるのはなぜですか？

測定部位、測定時の力加減、測定時刻、推定式によって結果は変わります。できるだけ同じ人が同じ条件で測定し、長期的な推移を中心に確認してください。結果画面に測定値のばらつきが大きいという案内が表示された場合は、再測定をおすすめします。詳しい制限は、アプリ内の「ガイド」ページをご覧ください。

Appleヘルスケアとの連携方法

計算後、「Appleヘルスケアに追加」を選択できます。初回は体脂肪率の書き込み権限を求めます。SkinfoldはHealthKitデータを読み取らず、個々の皮下脂肪厚の測定値、年齢、性別、参考区分、デバイス上の履歴も追加しません。各部位の測定値が1回だけでも追加できます。同じ部位に2回以上の測定値がある場合、差が3 mm（0.118 in）を超えると、追加前に再測定が必要です。

権限を拒否した場合、またはサンプルを削除する場合

Skinfoldのアクセス権はAppleヘルスケアアプリまたはiOSの「設定」で管理し、追加済みのサンプルはAppleヘルスケアアプリで表示または削除してください。AppleヘルスケアのサンプルとSkinfoldのデバイス上の履歴は別々に管理されるため、権限の拒否や一方の削除が他方を変更することはありません。

履歴を削除するにはどうすればよいですか？

「履歴」で個別の記録を削除するか、ツールバーの「履歴をすべて削除」を選んで全履歴を削除できます。

開発者へのお問い合わせ

アプリのバージョン、iPhoneのモデル、iOSのバージョン、問題を再現する手順を記載し、必要に応じてスクリーンショットを添付してください。メールまたは公開Issueに不要な個人の健康情報を記載しないでください。
