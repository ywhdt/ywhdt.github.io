记录与食品参考

在「记录 → 快速记录」中手动填写营养值或从食品库添加食物。食品参考可离线查询；不同来源、生熟状态和加工方式会影响营养值。配方估算仅作参考，不代表每家餐馆或每种做法的实测值。

试用、买断与恢复

在 App 内通过 App Store 主动领取 7 天试用；从首次领取起连续计算，不会自动续费或扣款。一次性买断后可继续新增和编辑。到期未买断时，已有记录仍可查看。

在「设置 → 使用与购买 → 恢复购买」中使用原购买的 App Store 账户。恢复使用权不需要注册 CalPace 账号，也不会恢复本地餐食或重新计时。领取试用、购买和恢复需要联网；有效使用权下日常记录与食品查询可离线使用。

模板、语言与 Apple 健康

常吃的餐可保存为模板，使用前按需调整。App 支持简体中文、繁体中文、英文、日文、韩文、德文、法文和西班牙文。在「设置 → App 语言」打开系统设置选择语言，已保存的名称和营养值不会重写。

Apple 健康为可选功能，需要你授权；不授权也可手动记录。身高、体重仅在你主动读取并授权时获取。关闭同步会保留已写入的数据，可在 App 内清理 CalPace 写入的健康数据，不触碰其他 App 的数据。

可选 AI 助手

AI 需要 iOS 27 或更新版本、支持 PCC 的兼容设备、PCC 服务就绪和有效使用权；部分地区不可用。默认使用 Apple Private Cloud Compute（PCC），无需 API Key，支持文字和照片。PCC 不提供网页搜索，也不会自动切换到其他服务商。

首次发送前，请查看接收方和数据内容，并同意发送。你可在「设置 → 配置饮食助手」中连接自己的 AI 服务。CalPace 不销售 API Key 或使用额度；第三方服务适用其自身条款、费用和额度限制。助手可以查看记录、撤销最近的修改；使用前请检查结果。

服务不可用或额度耗尽可能导致 AI 请求无法完成。有效使用权下，手动记录仍可使用。你可以取消请求，并保留草稿供稍后重试。

本机数据

App 需要 iOS 26 或更新版本。餐食、模板、计划、草稿和对话保存在本机。恢复购买不会恢复这些数据。换机或重新安装前，请保留所需记录。

设置中可管理或删除本机数据；删除无法撤销。API Key 需在助手设置中单独删除。附件、健康数据及服务商处理的详细说明见 隐私政策。
