如何记录？

在「记录」中点「快速记录」，填写内容或选择食物与份量，保存即可。点击顶部日期或左右滑动，可以查看其他日期。

如何启用 AI？

在「设置 → 饮食助手」选择 Gemini 或 OpenAI，填写自己的 API Key 并同意启用。服务商费用另计；无需启用 AI，也能手动记录。

如何恢复购买？

在「设置 → 使用与购买」点「恢复购买」，使用原购买 Apple 账户。恢复的是应用使用权，本地餐食不会随之恢复。

如何管理数据？

在设置中可管理 Apple 健康同步、清除对话或删除本地数据；API Key 在助手设置中单独删除。完整说明见 隐私政策。
