开始记录

在「记录」中打开「快速记录」，手动填写或搜索离线食物并选择份量，保存后计入当天摄入。点顶部日期展开选单，也可以左右滑动切换日期。未填写的营养素不会被当作零。

使用饮食助手

在「设置 → 饮食助手」选择 Gemini 或 OpenAI，保存自己的 API Key 并同意启用。返回「对话」即可发送文字；加号提供模型支持的图片与语音输入。App 购买不包含第三方 API 费用。

遇到网络中断时，保留当前对话，恢复连接后重试。已有输入与待处理内容会保留；也可以回到「记录」手动处理。不要为了重试而反复新建同一餐。

试用、买断与恢复

免费试用自首次领取起连续计算 7 天，卸载或重装不会重新计时。到期后仅可查看已有内容，隐私管理仍可使用。一次性买断后可继续使用全部功能，无订阅或自动续费。

换机或重装后，可在「设置 → 使用与购买」选择「恢复购买」，并使用原购买 Apple 账户。恢复的是应用使用权，不是本地餐食记录。价格与付款由 Apple 处理，以系统购买面板为准。

若商品暂时不可用，检查网络后在购买页重试。遇到账户验证或恢复错误，请先完成 Apple 系统验证；若仍有问题，将 App 显示的错误发给开发者，无需反复输入密码或删除 App。

TestFlight 的应用内购买不收取真实款项；Gemini / OpenAI 的实际调用仍可能产生服务商费用。

Apple 健康

在「设置 → Apple 健康」选择需要同步的营养素并授权。身高和体重可在「计划 → 身体资料」按需读取。关闭同步不会删除已经写入的数据，数据管理中可单独清理 CalPace 写入的健康数据。

数据与隐私

餐食和草稿保存在本机，目前不提供 CalPace 账号或餐食云同步。删除 App 可能移除本地记录；请不要把恢复购买当作餐食备份。

在设置的数据管理中可清除本地数据或对话；API Key 在饮食助手设置中单独删除。完整数据发送、保留与删除说明见 隐私政策。

关于营养参考

食物库来自 USDA、日本文部科学省与台湾食品药物管理署，条目中可查看具体来源。数据库参考与 AI 估算都可能与实际食物存在差异。CalPace 用于日常饮食记录，不提供医疗诊断或治疗建议。
