本机记录

CalPace 的餐食、模板、目标、身体资料、草稿、对话和助手偏好保存在本机。应用无需注册 CalPace 账号，手动记录不依赖 AI 服务。CalPace 不提供开发者运营的餐食云同步；恢复购买不会恢复已经删除的本地记录。

AI 服务与联网

你可以使用自己的 Gemini 或 OpenAI API Key 启用饮食助手。API Key 保存在本机系统钥匙串，用于向所选服务商验证身份，不写入餐食或对话文件，也不随设备备份迁移至另一台设备。

启用后发送消息，会将文字、所附且模型支持的图片或录音、当前餐食及简短对话上下文发送到所选服务商。为完成你的请求，助手也可能按需读取并发送相关餐食、模板、计划、身体字段及你要求记住的偏好，不会自动上传全部历史或 Apple 健康数据。图片和录音由当前模型直接处理，不会自动转给其他模型或转写服务。

开启联网搜索后，模型可使用本家的搜索服务。应用要求助手不把私人餐食历史、身体资料或密钥写入搜索词。搜索查询及相关上下文由所选服务按其条款处理，可在设置中关闭。API 和搜索费用由所用服务商账户承担，CalPace 的试用或买断不包含这些费用。

不同服务商、账户和服务可能采用不同的数据保留及使用规则。清除本机内容不会自动删除服务商已经处理的数据；请参阅 Gemini API 条款 与 OpenAI API 数据说明。

食品查询

离线食物参考数据随 App 提供，来自 USDA FoodData Central、日本文部科学省食品成分表 与 台湾食品药物管理署食品营养成分资料集。本地食物搜索不会向开发者发送搜索词。各条目的来源与许可可在食物详情查看；USDA 数据采用 CC0 / 公有领域规则，MEXT 数据按其二次使用规则标注出处，TFDA 数据采用 政府资料开放授权条款第 1 版。包装食品查询按需向 Open Food Facts 发送商品条码，获取公开食品资料；该查询工具不发送照片、录音或身体资料。数据来源与许可见 Open Food Facts。

照片与录音

相机和麦克风仅在使用对应功能时请求授权；相册只读取你通过系统选择器选中的照片。加入附件不会自动发送。图片发送前会重新处理，去除位置等元数据。

未发送或等待重试的附件会保留，主动清除对话时一并移除。关闭照片保留后，已处理的照片副本会移除；开启时保留当前及上一段对话的照片。录音处理成功后移除原录音。清除对话不会删除已保存餐食及随餐摘要。

Apple 健康

开启同步并授权后，已保存餐食的营养数据写入 Apple 健康，后续修改、删除和助手撤销也会同步。草稿不参与同步，缺失营养值不补成零，不读取或合并其他 App 的饮食记录。

餐食按日期和餐次记录。健康样本使用该日期原时区的餐次时间：早餐 08:00、午餐 13:00、晚餐 19:00、加餐 16:00，不代表精确进食时间。

身高、体重仅在你打开相应读取页面并授权时获取。选择测量后填入身体资料编辑页，保存后才保留，不会自动改变每日目标。已保存的身体资料可在你请求助手制定计划等场景中按需发送给所选模型。

关闭同步会保留已有健康数据。你可以单独清理 CalPace 写入的健康数据，也可以在清除本地数据时选择是否同时清理健康数据；不会删除其他 App 写入的数据。此前已经发起的健康清理仍会继续，失败任务会在再次打开 App 后重试。重新开启同步不会自动补写旧记录。

使用权与购买

购买和付款由 Apple 处理，CalPace 在本机核验交易信息以判断使用权。7 天试用从首次领取起连续计算，到期后仅可查看；一次性买断后可继续使用全部功能。恢复购买不重新计时，也不恢复已删除的餐食。

TestFlight 中的应用内购买使用 Apple 沙盒，不收取真实款项；第三方模型 API 的调用计费不属于该沙盒。

管理数据与反馈

在仅可查看的状态下，设置中的隐私管理仍可使用。你可以停用助手、关闭搜索、删除密钥、清除对话或清除本地数据。清除本地数据会移除餐食、模板、目标、身体资料、草稿、对话、附件、随餐摘要和助手偏好，并停用 AI；钥匙串中的密钥需单独删除。

你通过 TestFlight 或邮箱主动发送的反馈，用于排查问题和回复。请只提供排查所需内容，不要发送 API Key，并遮去不希望分享的餐食、照片或身体资料。若希望我们删除你发送的邮件反馈，可以联系上述邮箱；由 Apple 或 AI 服务商处理的数据还需使用相应平台的管理方式。

通过 TestFlight 测试时，Apple 还会按其服务规则向开发者提供安装版本、会话和崩溃等测试信息；经 TestFlight 提交的反馈也会提供给 Apple。详情见 Apple TestFlight 说明。

网站与政策更新

本支持网站由 GitHub Pages 托管，没有自行设置广告、分析脚本或追踪 Cookie。访问网站时，GitHub 可能处理 IP 地址等服务日志，详见 GitHub 隐私声明。这与 App 内的本地记录分开。

CalPace 未接入广告或第三方行为分析 SDK，也不出售你的饮食与健康资料。邮件服务会处理你主动发来的邮件及联系地址；我们只将反馈用于回复、排错与改进，在不再需要时删除，或根据你的请求处理。

若功能或数据处理方式改变，我们会更新本页及生效日期；新增向 AI 服务发送的数据范围会在发送前说明并征得同意。使用过程中如有隐私问题，请联系上述开发者邮箱。
