本机数据

餐食、模板、计划、身体资料、草稿、对话和助手偏好保存在设备本机。无需注册 CalPace 账号；不提供餐食云同步，不出售个人资料或用于广告追踪。

自配 API Key 保存在系统钥匙串，不写入餐食或对话文件，也不随设备备份迁移。使用自配服务时，密钥只发送给所选服务用于请求认证，不交给 CalPace 服务器；服务商还可能处理连接和用量信息。密钥需在助手设置中单独删除，不要通过邮件发送。

AI 与发送授权

默认使用 Apple PCC；也可连接你自己的 Google（Gemini API）或 OpenAI（API）服务。首次向每个服务发送前，独立确认窗口说明接收方、内容与用途，并取得你的明确授权。打开对话、添加照片或切换服务不会发送助手数据。可在设置 → 隐私政策中撤销授权；扩大数据范围需要重新授权。服务不可用时不会自动转交其他服务商。

你提交的文字、所选照片和相关对话。根据任务需要，助手还可能读取并发送相关餐食及营养记录、模板、目标计划、已保存的身体与活动资料（包括性别、年龄、身高和体重），以及饮食偏好。

用于理解你的请求、估算营养和执行你要求的记录操作。

PCC 不提供网页搜索。支持搜索的服务可按任务使用搜索，查询及相关上下文由其处理。包装食品查询仅将商品条码发送至 Open Food Facts，不发送照片。

服务商与数据保护

Apple PCC：Apple 表示，PCC 数据仅用于完成请求，不存储，也不向 Apple 开放访问。这些保护适用于 PCC，不适用于其他服务商。

Google（Gemini API）：请使用关联有效 Cloud Billing 账户的 Gemini API 项目。Google 表示，付费服务不将提示或回答用于改进产品，但会按安全要求保留数据。未付费服务可能用于产品改进和人工审阅，且不得接收个人信息。CalPace 无法仅凭 API Key 验证账单状态。

OpenAI（API）：OpenAI API 内容默认不用于训练，除非你主动选择共享。安全日志可能保留内容，通常最长 30 天，法律或安全原因可能延长。CalPace 关闭响应存储，这不等于零保留。

CalPace 将请求直接交给你选择的服务，不运营 AI 请求服务器，不将提交内容用于广告跟踪。服务商的处理遵循上列数据保护与安全规则；你的 API 账户设置可能影响保留或主动启用的共享。使用联网搜索时，Google 可能为该功能保留提示、上下文和结果 30 天。CalPace 不请求服务商保存响应，但这不等于消除安全日志或特定功能的保留。

照片

拍摄照片时按需申请相机授权，相册仅读取你选中的照片。加入附件不会自动发送；图片发送前重新处理以去除位置等元数据。

未发送或待重试的附件会保留在本机。照片保留开启时保存当前及上一段对话的照片；关闭时移除已处理的照片。清除对话会移除相关附件。

食品查询与来源

离线食品查询不发送搜索词。参考资料来自 USDA、日本文部科学省、台湾食品药物管理署、ANSES Ciqual 和英国 CoFID；CalPace 另提供明确标示的参考配方估算。具体出典、许可、状态和原始营养定义可在 App 内查看，译名不改变原始营养值。

若助手查询包装食品，该查询仅将商品条码发送给 Open Food Facts；图片不交给该条码查询接口。

Apple 健康

经授权可将餐食营养写入 Apple 健康，并同步后续编辑或删除。身高、体重仅在主动请求和授权后读取，保存后才保留。已保存的身高、体重，包括从 Apple 健康取得的数值，在取得助手发送授权后，可能用于相关请求并交给所选 AI 服务；不会自动上传完整健康历史。关闭同步保留健康数据；清理只删除 CalPace 写入的样本。

购买与删除

购买和付款由 Apple 处理。CalPace 在本机核验交易和原试用时间，判断有效使用权。恢复购买不会恢复本地餐食，也不重新计算试用期限。

可在设置 → 隐私政策中撤销全部助手发送授权，停止正在进行的请求；本机记录与 API Key 保留，各服务再次发送前须重新授权。撤销或删除本机数据不能清除服务商已接收的内容；可通过服务商的隐私联系方式或账户控制请求保留与删除处理。也可在设置清除对话或删除本机数据；删除无法撤销，操作前会显示范围。密钥需单独删除：当前服务商的密钥可在饮食助手设置中删除；所有本机助手密钥可在「设置 → 数据管理」中删除。这些管理功能在仅查看状态下仍可使用。

反馈与网站

你邮件中主动提供的联系信息和内容仅用于回复及排错，不再需要时或按你的请求删除。请勿发送密钥或密码。TestFlight 的版本、会话、崩溃及你主动提交的反馈由 Apple 按其规则处理。

网站由 GitHub Pages 托管，GitHub 可能处理 IP 等访问日志。本网站不使用广告、分析脚本或追踪 Cookie。政策更新和扩大 AI 发送范围时会在适用处说明并征求同意。
