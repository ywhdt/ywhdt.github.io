本机数据

餐食、模板、计划、身体资料、草稿、对话和助手偏好保存在设备本机。无需注册 CalPace 账号；本应用不提供餐食云同步，也不出售个人资料或用于广告追踪。用户自行配置的 API Key 保存在本机系统钥匙串，不写入餐食或对话文件，也不随设备备份迁移到另一台设备。

AI 与联网

打开对话或切换服务商不会发送数据。仅在系统、设备、地区和服务条件允许时提供 AI。默认使用 Apple Private Cloud Compute（PCC），无需 API Key；也可自行连接 Gemini 或 OpenAI。首次发送前说明接收方和内容，取得你的同意后才发送。服务不可用或额度耗尽时，不会自动转交其他服务商。

主动发送的文字、当前请求的相关对话及附件交给所选服务商处理。为完成请求，助手按需读取并发送相关餐食、模板、计划、已保存的身体字段与偏好，不会自动上传全部历史或 Apple 健康数据。服务商的数据保留与处理适用其条款；自行配置服务时请先阅读相关说明。

PCC 支持文字和照片，不提供网页搜索。支持搜索的服务可默认按任务调用搜索，查询和相关上下文由相应服务处理。旧个人设置保留。你可以取消请求或清除助手数据。

使用 AI 前会检查系统报告的 PCC 可用状态。不支持 PCC 时，不提供任何 AI 服务，包括自行配置的服务；餐食等本机功能仍可使用。App Store 的下载、购买及恢复由 Apple 处理。

照片

拍摄照片时按需申请相机授权，相册仅读取你选中的照片。加入附件不会自动发送；图片发送前重新处理以去除位置等元数据。

未发送或待重试的附件会保留在本机。照片保留开启时保存当前及上一段对话的照片；关闭时移除已处理的照片。清除对话会移除相关附件。

食品查询与来源

离线食品查询不发送搜索词。参考资料来自 USDA、日本文部科学省、台湾食品药物管理署、ANSES Ciqual 和英国 CoFID；CalPace 另提供明确标示的参考配方估算。具体出典、许可、状态和原始营养定义可在 App 内查看，译名不改变原始营养值。

若助手查询包装食品，该查询仅将商品条码发送给 Open Food Facts；图片不交给该条码查询接口。

Apple 健康

授权后可写入餐食营养，并同步后续修改或删除。身高、体重仅在你主动读取并授权时获取，保存后才保留；这些已保存的身体资料可用于相关 AI 请求。关闭同步保留已有健康数据，可在 App 中清理 CalPace 写入的数据，不触碰其他 App 的健康数据。

购买与删除

购买和付款由 Apple 处理。CalPace 在本机核验交易和原试用时间，判断有效使用权。恢复购买不会恢复本地餐食，也不重新计算试用期限。

可在设置清除对话或删除本机数据；删除无法撤销，操作前会显示范围。密钥需单独删除：当前服务商的密钥可在饮食助手设置中删除；所有本机助手密钥可在「设置 → 数据管理」中删除。本机删除不等于删除服务商已处理的数据。这些管理功能在仅查看状态下仍可使用。

反馈与网站

你邮件中主动提供的联系信息和内容仅用于回复及排错，不再需要时或按你的请求删除。请勿发送密钥或密码。TestFlight 的版本、会话、崩溃及你主动提交的反馈由 Apple 按其规则处理。

网站由 GitHub Pages 托管，GitHub 可能处理 IP 等访问日志。本网站不使用广告、分析脚本或追踪 Cookie。政策更新和扩大 AI 发送范围时会在适用处说明并征求同意。
