隐私政策

你的记录、所用服务，以及管理数据的方式。

生效日期：2026 年 9 月 12 日

开发者：ZHANG WENTIAN · wentianzh.apps@outlook.com

本机数据

餐食、计划、身体资料、草稿和对话保存在本机，无需注册 CalPace 账号。API Key 保存在系统钥匙串，不随备份迁移到另一台设备。CalPace 不提供餐食云同步，不出售个人资料或用于广告追踪。

AI 与联网

使用饮食助手时，你发送的文字、照片、录音及相关对话会交给所选的 Google（Gemini）或 OpenAI 处理。助手也会为完成请求，按需读取相关餐食、模板、计划、已保存的身体资料和偏好；不会自动上传全部历史或 Apple 健康数据。你可以停用助手或关闭联网搜索。

开启搜索后，查询和相关上下文由所选服务商处理。服务商费用另计，数据使用与保留遵循其条款；清除本机内容不会删除服务商已处理的数据。Gemini 免费服务条款要求不要提交个人、敏感或保密信息，处理个人资料请使用符合条款的账户。

Gemini API 条款 · OpenAI 数据说明

照片与录音

相机、麦克风按需授权，相册只读取你选中的照片。附件在你发送前留在本机；照片发送前会去除位置等元数据。

未发送或待重试的附件会保留。开启照片保留时，保存当前及上一段对话的照片；关闭后移除已处理的照片。录音处理成功后删除，清除对话会移除相关附件。

食品查询

离线食物查询不发送搜索词，参考来源为 USDA、日本文部科学省 和 台湾食品药物管理署。具体来源与许可可在 App 内查看。包装食品查询仅向 Open Food Facts 发送商品条码。

Apple 健康

授权后，CalPace 可写入餐食营养数据，并同步后续修改或删除；身高、体重只在你主动读取并授权时获取。保存的身体资料可在相关 AI 请求中使用。

关闭同步会保留已有健康数据。你可以清理 CalPace 写入的数据，其他 App 的健康数据不受影响。

购买与数据管理

购买和付款由 Apple 处理，CalPace 在本机核验交易以判断使用权。恢复购买不会恢复本地餐食。

你可以停用助手、清除对话或删除本地数据，API Key 需在助手设置中单独删除。这些隐私管理功能在仅查看状态下仍可使用。

反馈与网站

邮件反馈中的联系地址和主动提供的内容仅用于回复与排错，不再需要时或按你的请求删除。请勿发送 API Key 或账户密码。若使用 TestFlight，Apple 会按其规则提供版本、会话、崩溃信息及你提交的反馈，详见 TestFlight 说明。

网站由 GitHub Pages 托管，GitHub 可能处理 IP 地址等访问日志，详见 GitHub 隐私声明。本站没有广告、分析脚本或追踪 Cookie。

隐私问题或删除反馈的请求，请联系上述邮箱。数据处理方式变化时，我们会更新本页；新增 AI 数据发送范围会在发送前说明并征得同意。
